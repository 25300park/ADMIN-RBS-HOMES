브리프 `$ARGUMENTS`의 **1단계만** 진행합니다.

## 시작
1. `docs/briefs/$ARGUMENTS-*.md`를 찾아 읽습니다. 없으면 여기서 멈추고 알려 주세요.
2. `docs/approval-policy.md`와 `CLAUDE.md`(또는 `AGENTS.md`)를 읽습니다. 브리프의 "범위 밖"을 지킵니다.
3. 작업은 **`origin/main` 기준 별도 git worktree**에서 합니다. 레포 루트의 미커밋 변경은 읽지도, 건드리지도 않습니다.

## 하면 안 되는 것
- 코드와 문서 수정, 커밋, 푸시, PR 생성
- 운영 DB 접속, `.env*` 읽기, 비밀값 출력, 배포
- 브리프에 없는 조사 확대 (발견한 것은 "범위 밖 발견"으로만 보고)

## 보고 (이 형식으로)
1. 브리프 2번의 1단계 항목별 결과 (파일 경로와 줄 번호 포함)
2. **대표가 정해야 할 것**: 번호를 붙인 질문 목록과 각 선택지, 추천안과 이유
3. 2단계 계획: 파일별 변경 예정, 위험, 되돌리는 방법
4. 범위 밖이라 손대지 않았지만 발견한 것 (중요도 표시)
5. 비밀값, 개인정보를 출력하지 않았다는 확인

## 마무리
worktree를 정리하고, **대표의 승인 문장을 기다리며 멈춥니다.** 승인 없이 2단계로 넘어가지 않습니다.
